# orvilo-apercu

Démonstration interactive Orvilo avec des personnes, sorties et messages fictifs. Les interactions restent en mémoire dans chaque navigateur et disparaissent au rechargement. Aucun compte réel, email, SMS ou push n’est créé ou envoyé. La carte est schématique et les liens externes sont neutralisés.

Accueil, recherche, création de sortie, conversation, profil et réglages sont disponibles. Le bouton Réinitialiser restaure les données fictives.

Le nom et le logo Orvilo sont des propositions de travail. Les licences tierces sont incluses dans THIRD-PARTY-NOTICES.txt.
